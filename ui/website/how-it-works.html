How it works, step by step

1

Install and start — no account needed

Download on Windows, macOS, iOS, Android, or Linux. Or use the web PWA. No account, no signup, no credit card. Your egg appears in under 2 minutes.

2

Choose your model

Free tier uses community open-source models locally. Core Pro and above get access to Claude, GPT-4, and Gemini. You can connect your own API keys at any tier.

3

Your companion builds a memory

As you interact, your companion creates encrypted memory entries — semantically tagged, emotionally indexed. Stored locally using pgvector. Only synced to cloud if you enable it, with your encryption key.

4

Context is always present

Every conversation is informed by your history. Your companion recalls relevant memories, your preferences, your last conversation. It feels continuous — because it is.

5

Switch models without losing context

The companion layer is independent of the model layer. Switch from Claude to Llama mid-conversation — your companion reorients the new model with your relevant context automatically.

6

Export or delete anytime

Full export to JSON, Markdown, or vector embeddings. Deletion via cryptographic erasure — your key is destroyed and the data is mathematically unrecoverable. No "we'll delete within 30 days" promises.

Under the hood

Vector Memory (pgvector + HNSW)

Memories stored as semantic embeddings. Approximate nearest-neighbor search retrieves relevant context in milliseconds.

Emotional Tagging

Each memory tagged with valence (positive/negative), arousal level, and dominant emotion. Context retrieval is emotionally aware.

Model Bridge (OpenAI-compatible API)

Any OpenAI-compatible API works. Local models via Ollama or LM Studio. Companion layer abstracts the model entirely.

Client-side Encryption

AES-256 encryption with client-held keys. Server stores ciphertext only. We mathematically cannot read your data.

Governance Engine

Decision transparency log. Every AI decision recorded with reasoning. Override controls always available to you.

MCP Protocol

Built on the Model Context Protocol — the emerging standard for AI tool and memory integration. Forward-compatible with the AI ecosystem.
