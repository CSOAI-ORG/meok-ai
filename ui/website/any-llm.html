The companion persists. The brain is swappable.

This is the key architectural insight that makes MEOK different. Most AI products are tightly coupled to one model — when the model changes (or disappears), so does your relationship with it.

MEOK's companion layer holds your personality preferences, memory, emotional context, and conversation style. The model just provides the reasoning. You can swap models mid-conversation and your companion doesn't forget who you are.

  • Personality and preferences stored in companion layer
  • Memories persist across all model switches
  • Each model given relevant context from your history
  • Compare models side-by-side for the same question

Bring your own keys

Prefer to use your own API subscriptions? Connect your OpenAI, Anthropic, or Google API key directly. MEOK never stores your keys in our cloud — they live in your local encrypted keychain.

  • API keys encrypted in local OS keychain
  • Direct API calls — we're not a proxy harvesting responses
  • Works with enterprise API keys and private endpoints
  • Self-hosted model support (Ollama, LM Studio, vLLM)

Why this matters for your privacy

🔑

No middleman on your keys

When you use your own API key, requests go directly to the model provider. MEOK isn't logging your conversations or using them to train anything.

🏠

Local models: zero data leaves

Running Llama or Mistral locally? Nothing leaves your device. The most private setup possible.

🔄

No vendor lock-in

If your preferred model raises prices, gets acquired, or changes terms — switch with one tap. Your memory and companion stay with you.
