What's open and what isn't

We're transparent about the boundary between open and proprietary.

Open source (MIT licensed)

  • Client application (all platforms)
  • Encryption and key management layer
  • Memory storage engine (pgvector integration)
  • Model bridge and API key handling
  • Companion layer and personality system
  • Onboarding and egg hatching flow
  • Export and data portability tools
  • MCP server protocol implementation

Proprietary (cloud infrastructure)

  • Cloud sync relay (ciphertext only — you can't read it, neither can we)
  • Billing and subscription management
  • Account authentication server
  • Analytics aggregation (no PII, aggregate only)

The proprietary components touch no user data in readable form. They are not where your privacy lives or dies — that's all in the open-source client.

Verify our privacy claims yourself

Here's the specific code to read if you want to validate our key claims.

# Verify: no data leaves your device without encryption
grep
-r "cloud_sync" meok/core/memory/ # All sync goes through encryption layer

# Verify: conversations don't train models
grep
-r "training\|fine_tune\|finetune" meok/mcp/ # Should return nothing

# Verify: cryptographic erasure on delete
grep
-r "key_destroy\|cryptographic_erase" meok/core/ # See the implementation

# Verify: API keys stored in OS keychain, not cloud
grep
-r "keychain\|SecretService" meok/auth/ # Platform keychain integration
