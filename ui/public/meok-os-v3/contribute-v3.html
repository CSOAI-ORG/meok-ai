🤝 Contribute to MEOK

PR guide · Dev setup · Code review · BFT voter · MIT license. Open source. 220+ repos.

🚀 Quick start (5 min)

# 1. Fork the repo
git clone https://github.com/YOUR-USERNAME/meok-os-v3.git
cd meok-os-v3

# 2. Install
npm install
pip install -r requirements.txt

# 3. Run dev server
npm run dev

# 4. Open browser
open http://localhost:3000

# 5. Make your change, run tests
npm test
python3 -m pytest

# 6. Submit PR
git checkout -b feature/my-change
git commit -m "feat: my change"
git push origin feature/my-change
# Open PR on GitHub

📋 PR checklist

  1. ✓ Tests pass (npm test + pytest)
  2. ✓ Coverage > 90%
  3. ✓ Documentation updated
  4. ✓ Changelog updated
  5. ✓ License header in every file (MIT)
  6. ✓ No telemetry, no analytics, no third-party deps
  7. ✓ 13 regulatory frameworks respected (GDPR, EU AI Act, etc.)
  8. ✓ 6 COAI baseline gates verified
  9. ✓ Ed25519 sigil chain (if code change)
  10. ✓ BFT Council vote (if breaking change)

🤝 Code review

All PRs are reviewed by:

  • 1 maintainer (Nicholas Templeman, the founder)
  • 1 BFT Council member (community)
  • 1 Horus safety check (12 lenses)

Reviews typically take 1-3 days. Breaking changes require BFT Council vote (5 voters, unanimous yes).

🏛️ BFT voter application

BFT voters are the 85 community seats across 11 BFT councils. Apply via GitHub Discussions.

📋 5 voter types

  • community-developer — contributor to the hive
  • community-user — end user in production
  • community-ethics — ethics review (care, harm, compliance)
  • community-operator — operator who runs the hive at scale
  • domain-expert — domain expert in the hive's industry

📋 Eligibility

  • At least 10 merged PRs
  • At least 6 months of community participation
  • Agree to the 7 sovereign principles
  • Endorsement from 1 existing voter (BFT)
