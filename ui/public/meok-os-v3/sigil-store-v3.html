🛡️ Hash-chained integrity

Every sigil is hash-chained to the previous one. Tampering with any sigil invalidates all subsequent sigils.

sigil_n = SHA-256(sigil_(n-1) + line_n + ts_n + author_n + sig_n)

To verify the chain: start with the genesis sigil, hash it forward, compare to each subsequent sigil. Any mismatch = tampered.
