🔧 MEOK OS v3 Dev Tools

For developers building on the MEOK sovereign substrate. 220+ MCP tools · 1 unified API · MIT license.

📜 MEOK OS v3 SDK (npm)

npm install @meok-os/sdk

import MEOK from '@meok-os/sdk';
const scholar = await MEOK.character.get('scholar');
await MEOK.council.vote('proposal_id', 'yes');

🐍 MEOK OS v3 SDK (pip)

pip install meok-os

from meok_os import MEOK
meok = MEOK()
meok.character.get('scholar')
meok.council.vote('proposal_id', 'yes')

🔧 MCP Server Scaffolder

Auto-generate a new MCP server from a single config.

python3 lib/scaffolder.py \
  --name meok-foo-mcp \
  --description "Foo does bar" \
  --hive api-gateway \
  --tools 12

🛡️ Sovereignty Middleware

Drop-in Express.js middleware for 7 sovereignty headers.

import sovereignty from '@meok-os/middleware';
app.use(sovereignty);

📜 Sigil Chain Auto-Anchor

Auto-anchor every action to the SOV3 sigil chain.

from meok_os import sigil
sigil.anchor('character.birth', 'nick', 'scholar', {'archetype': 'sage'})

🗳️ BFT Voter Weight Calculator

Compute XP-weighted voter reputation.

from meok_os import voter_weight
voter_weight.compute(years=2.3, cast=47, available=50, aligned=43)
