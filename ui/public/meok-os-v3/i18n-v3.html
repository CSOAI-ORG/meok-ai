📋 Locale format

// BCP 47 locale tag
[language]-[script]-[region]-[variant]
   ↓        ↓        ↓        ↓
   ja      Jpan      JP      hepburn
   zh      Hans      CN      pinyin
   en               GB      oxendict
   pt               BR      formal

// Examples
"en-GB"      // British English
"en-GB-oxendict"  // British English, Oxford dictionary
"zh-Hans-CN"  // Simplified Chinese, China
"zh-Hant-TW"  // Traditional Chinese, Taiwan
"es-MX"     // Mexican Spanish
"pt-BR"     // Brazilian Portuguese
"ar-SA"     // Saudi Arabic (RTL)
"he-IL"     // Israeli Hebrew (RTL)
"ja-JP"     // Japanese
"ja-JP-hepburn"  // Japanese, Hepburn romanization

🛡️ Sovereign i18n

MEOK's i18n is sovereign. Each user's preferred locale is stored on the sigil chain (encrypted with the user's public key). The user controls their own locale.

MEOK supports RTL (right-to-left) languages: Arabic, Hebrew, Urdu, Persian. Bidirectional text rendering.

MEOK supports per-character locale. A Sage companion can speak British English while a Trickster companion speaks Australian English. 50+ languages × 9 archetypes = 450+ character-language combinations.
