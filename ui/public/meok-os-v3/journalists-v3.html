🛡️ The press freedom pledge

  1. All sources are sovereign (SOV3 + Ed25519 + 13 frameworks)
  2. End-to-end encrypted (AES-256-GCM + TLS 1.3)
  3. Never trained on, never sold, never shared with third parties
  4. Right to delete (GDPR Art 17) — 1-click hard delete + audit receipt
  5. Right to data portability (GDPR Art 20) — 1-click export
  6. Shield laws respected (US), source protection (UK/EU)
  7. MEOK will never cooperate with subpoenas (would be a backdoor; we don't have one)
  8. If served a subpoena, we will challenge it in court + notify the journalist
  9. Sovereign compute (EU + US, never cross-border without consent)
  10. Open source (MIT) — every journalist can audit the code
