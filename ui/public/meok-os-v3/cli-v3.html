💻 meok-os-cli

Cross-platform CLI. Sovereign. MIT. 30 commands. Install via brew + pip + cargo.

📦 Install

# macOS
brew install meok-os

# Linux
curl -fsSL https://meok.ai/install.sh | sh

# Windows
iwr -useb https://meok.ai/install.ps1 | iex

# Python
pip install meok-os-cli

# Rust
cargo install meok-os-cli

# From source (any platform)
git clone https://github.com/csoai-org/meok-os-cli
cd meok-os-cli
make install

🚀 Quick start

# 1. Login
meok auth login

# 2. Birth a character
meok character birth sage "The Scholar"

# 3. Vote on a proposal
meok bft vote --proposal MEOK-9F4A2B7C --vote yes

# 4. Export your data
meok sovereign export --format json --output ./my-data.json

# 5. Verify an attestation
meok attest verify MEOK-9F4A2B7C
