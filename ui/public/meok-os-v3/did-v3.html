🛡️ What is decentralized identity?

A Decentralized Identifier (DID) is a globally unique identifier that doesn't require a centralized authority to issue, resolve, or revoke. W3C standard since 2022.

MEOK will use DIDs as the primary identifier for users, characters, families, BFT councils, and MCP servers. Each DID has a private key (held by the user) and a public key (verifiable by anyone).

Format: did:meok:1a2b3c... (MEOK method) or did:key:z6Mk... (key method, MEOK-compatible).
