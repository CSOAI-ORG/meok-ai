🛡️ The privacy pledge

  1. End-to-end encrypted (AES-256-GCM + TLS 1.3)
  2. No third-party access (not even MEOK)
  3. Per-message keys (forward secrecy)
  4. Right to delete (GDPR Art 17) — 1-click hard delete
  5. Right to export (GDPR Art 20) — 1-click export to JSON/CSV/Parquet
  6. No tracking, no analytics, no profiling
  7. Open source (MIT) — every user can audit the encryption
  8. Self-hostable (Q4 2026) — for paranoid users
