MEOK OS v3 will be quantum-safe by Q1 2027. NIST PQC standard. Hybrid Ed25519 + ML-DSA + Kyber. Sovereign. MIT.

🛡️ Why quantum-safe matters

In 2026, NIST released the first post-quantum cryptography (PQC) standards: FIPS 203 (ML-KEM/Kyber), FIPS 204 (ML-DSA/Dilithium), FIPS 205 (SLH-DSA/SPHINCS+). These are designed to resist attacks by quantum computers.

Ed25519 (used by SOV3 today) is not quantum-safe. A sufficiently powerful quantum computer could derive a private key from a public key. MEOK is migrating.

The MEOK approach: hybrid. Ed25519 + ML-DSA + Kyber. The hash chain remains hash-chained (SHA-256 is not weakened by quantum). Only the signatures get upgraded.

🔐 The 4 algorithms

🔑 Ed25519 (current)

256-bit elliptic curve. Fast, small signatures (64 bytes). Used by SOV3, sigil chain, all 18 hives. Not quantum-safe. MEOK will keep using it as a fallback forever.

Status: active today · Quantum-safe: ✗ · Will be deprecated Q1 2027

🔐 ML-DSA (Dilithium-3, FIPS 204)

Lattice-based. Quantum-safe. 1,952-byte signatures. 4x larger than Ed25519 but quantum-resistant. Standard for the next 20 years.

Status: planned Q1 2027 · Quantum-safe: ✓ · Will be primary

🔐 ML-KEM (Kyber-768, FIPS 203)

Lattice-based KEM. Quantum-safe. 1,088-byte public keys. For key exchange, not signing. MEOK will use it for sovereign export encryption.

Status: planned Q1 2027 · Quantum-safe: ✓ · Will be primary for KEM

🔐 SLH-DSA (SPHINCS+, FIPS 205)

Hash-based. Quantum-safe. 8,192-byte signatures. Stateless. Slow. For high-stakes (legal, financial, government). MEOK will use it for notarization.

Status: planned Q2 2027 · Quantum-safe: ✓ · Will be for notarization

📊 Migration impact (estimated)

  • Signature size: 64 bytes → 1,952 bytes (~30x larger)
  • Verify time: ~50µs → ~200µs (~4x slower)
  • Sign time: ~30µs → ~500µs (~17x slower)
  • Hash chain: unchanged (SHA-256, quantum-safe)
  • Sigil storage: +30% per sigil (acceptable for audit trail)
  • Compatibility: 100% backward-compatible (old Ed25519 sigils stay valid)
  • Migration cost: ~$50K dev + ~$10K audit (independent cryptographer)
  • Target launch: Q1 2027 (NIST PQC mandatory in US gov by 2035)
