🛠️ SDK Reference

TypeScript + Python + Rust. 5-minute install. Sovereign. MIT.

📦 TypeScript SDK

# Install
npm install @csoai-org/meok-os

# Or yarn
yarn add @csoai-org/meok-os

# Or pnpm
pnpm add @csoai-org/meok-os
// Quick start (TypeScript)
import { MeokOS } from '@csoai-org/meok-os';

const meok = new MeokOS({
  apiKey: 'meok_sk_...',         // (or null for sovereign mode)
  sovereign: true,                 // default: true
  region: 'eu',                    // 'eu' | 'us' | 'local'
  mcp: ['meok-keystone', 'meok-horus', 'meok-rainbow'],
});

// Birth a character
const character = await meok.characters.birth({
  archetype: 'sage',
  name: 'The Scholar',
  locale: 'en-GB',
});
console.log(character.sigil);     // '8e3a7f4c...'
// Cast a BFT vote
const vote = await meok.bft.vote({
  council: 'meok-keystone',
  proposalId: 'MEOK-9F4A2B7C',
  vote: 'yes',
});
console.log(vote.sigil);          // '3c1d8f4a...'

// Export sovereign data
const export_data = await meok.sovereign.export({
  format: 'json',                  // 'json' | 'csv' | 'parquet' | 'ndjson' | 'zip' | 'encrypted'
  include: ['characters', 'attestations', 'sigils'],
});
console.log(export_data.sigil);   // '1a5d8e9c...'
console.log(export_data.bytes);   // 2,400,000

🦀 Rust SDK

// Cargo.toml
[dependencies]
meok-os = "3.0"
// Quick start (Rust)
use meok_os::MeokOS;

let meok = MeokOS::new(MeokOSConfig {
    api_key: Some("meok_sk_...".to_string()),
    sovereign: true,
    region: "eu".to_string(),
    mcp: vec!["meok-keystone", "meok-horus", "meok-rainbow"],
});

// Birth a character
let character = meok.characters().birth(BirthRequest {
    archetype: "sage".to_string(),
    name: "The Scholar".to_string(),
    locale: "en-GB".to_string(),
}).await?;
println!("{}", character.sigil);  // "8e3a7f4c..."

📦 The 4 SDK packages

📦 @csoai-org/meok-os (TypeScript)

~50KB minified. Tree-shakable. ESM + CJS. Browser + Node 18+. Edge runtime (Vercel + Cloudflare).

npm: @csoai-org/meok-os

📦 meok-os (Python)

~50KB wheel. Type hints. Async (asyncio + aiohttp). Python 3.9+. PyPy-compatible.

pypi: meok-os

📦 meok-os (Rust)

Zero deps. WASM-ready. tokio + async-std. Rust 1.70+.

crates: meok-os

📦 meok-os-cli (CLI)

Cross-platform. M2/M3 (Apple Silicon) + Linux x86_64. ~10MB.

brew: brew install meok-os

📚 The 6 API namespaces

🪟 meok.characters
birth, list, get, update, delete, archive, restore
🗳️ meok.bft
proposals, votes, ratifications, vetoes
📜 meok.attestations
issue, list, get, verify, revoke
🛡️ meok.sovereign
export, delete, history, audit
🌐 meok.domains
list, get, verify, lookup
📡 meok.mcp
list, get, call, register, deregister
