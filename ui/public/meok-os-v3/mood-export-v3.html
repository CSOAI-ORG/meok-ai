📤 The 6 export formats

📄 JSON

Universal. Easy to parse. Default format. Includes audio as base64 (large).

📊 CSV

Spreadsheet-friendly. Excel + Google Sheets compatible. No audio.

📦 Parquet

Big-data friendly. Compressed. Pandas / Polars / DuckDB. No audio.

📋 NDJSON

Streaming. One JSON per line. For log analysis. No audio.

📁 ZIP

JSON + audio files (WAV). For archival. Largest size.

🔐 Encrypted

AES-256-GCM encrypted. For sharing. Decrypt with your private key.
