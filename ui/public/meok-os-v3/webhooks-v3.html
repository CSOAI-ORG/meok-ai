🪝 The 12 webhook event types

🪟 character.birth

A new character was born

🪟 character.stage

A character reached a new stage (Curious/Adept/Sage/Oracle/Sovereign)

🪟 character.delete

A character was deleted (GDPR Art 17)

🗳️ bft.proposal.submitted

A new BFT proposal was submitted

🗳️ bft.vote.cast

A BFT vote was cast (any council, any voter)

🗳️ bft.proposal.ratified

A BFT proposal was ratified (5/5 yes)

🗳️ bft.proposal.vetoed

A BFT proposal was vetoed (2/3 BFT)

📜 attestation.issued

A COAI attestation was issued

🛡️ sovereign.exported

A sovereign export was issued

🛡️ sovereign.deleted

A sovereign delete was issued (GDPR Art 17)

📡 mcp.called

An MCP tool was called

🆔 did.rotated

A DID was rotated (key rotation)

X-MEOK-Sovereign: true

}

Signature verification:

// Node.js
const crypto = require('crypto');

const signature = req.headers['x-meok-signature'];
const [t, v1] = signature.split(',');
const timestamp = t.split('=')[1];
const providedHash = v1.split('=')[1];

const expectedPayload = `${timestamp}.${JSON.stringify(req.body)}`;
const expectedHash = crypto
  .createHmac('sha256', process.env.MEOK_WEBHOOK_SECRET)
  .update(expectedPayload)
  .digest('hex');

if (expectedHash !== providedHash) {
  return res.status(401).send('Invalid signature');
}

🛡️ Webhook guarantees

🔐 Sovereign

Every webhook is Ed25519-signed + SOV3-anchored. Verifiable. Tamper-evident.

🔁 At-least-once

Retries up to 24h with exponential backoff. Idempotency key in every payload.

⏱ 5-second timeout

Your endpoint must respond within 5 seconds. Slower = retry. 5xx = retry.

🌍 EU + US regions

Pick your region. Sovereign. Never cross-border without consent.
